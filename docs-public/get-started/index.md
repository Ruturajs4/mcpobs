# Get started

Three pages, in order:

1. **[Quickstart](quickstart.md)** — run the stack and send your first spans.
2. **[Your first trace](first-trace.md)** — read a trace and understand what
   each row is telling you.
3. **[Lite deployment](lite.md)** — the same product, four containers instead
   of eleven, no Kafka. Read this before `make up` if you are evaluating
   self-hosting and want the smaller footprint first.

If you already have a server and just want it reporting, go straight to the
[Python SDK](../integrate/python-sdk.md).
